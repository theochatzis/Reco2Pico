# v1.0.0_CMSSW_15_0_X

- **Date:** 2026-10-19
- **Branch:** `CMSSW_15_0_X`
- **CMSSW release:** CMSSW_15_0_4 (el9_amd64_gcc12)
- **Previous tag:** none (first tagged release)
- **Same shared features as:** v1.0.0_CMSSW_20_1_X

## Contents

First tagged release, a snapshot of everything so far:

- Pico production from miniAOD, AOD and RECO (`PicoProducer/python/workflows/`),
  table groups `event`, `muons`, `electrons`, `jets`, `pfcands`, `tracks`,
  `vertices`, `pfclusters`, `rechits` (with `fullEcalRecHits`), `pfblocks`.
- Simulation truth on RECO MC: `genparts`, `sim` (SimTrack/SimVertex, SimJet
  from the calorimeter-entrance particles by default, SimBoundaryJet,
  ancestry-based SimJet to GenJet matching, TrackingParticle links).
- Calorimeter and PF truth: `simcalo` (per-particle deposits, ideal PF,
  SimCalo/SimPF jets) and `recojets` (PF candidates attributed to simulated
  particles, re-clustered PF/CHS/Puppi jets).
- `calodigis`: EB/EE/HBHE digis from the RAW file given as secondary input.
- `pileupTruth`: pile-up attribution for classically mixed samples.
- Workflows `run3_rawsim` (GEN-SIM-RAW to RECO with truth kept, to Pico) and
  `run3_mix` (classical pile-up mixing chain); Condor tools with
  `CONDOR_WORKDIR`; default outputs under
  `/eos/cms/store/group/phys_jetmet/tchatzis/reco2pico/`.
- Analyses `analysis/TrueJES` and `analysis/CaloPulses`, with their notes in `docs/`.

## Validation

- build: `scram b` in CMSSW_15_0_4
- `RECO_to_pico_cfg.py` loads with all table groups enabled
- productions with this code: the TrueJES studies (run3_rawsim, run3_mix)
